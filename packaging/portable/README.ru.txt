FORGE {version} — помощник по индустрии EVE Online
=====================================================

Что это
-------
Локальная программа: точное количество материалов и реальная себестоимость
постройки по чертежу, что выгодно строить, расписание джобов по всем
персонажам, отчёты по стройкам. Работает только на этом компьютере и общается
только с официальными серверами EVE (ESI, вход EVE, сервер картинок) и
Fuzzwork (статические данные игры, агрегаты рынка).

Как запустить
-------------
1. Распакуй папку ЦЕЛИКОМ куда угодно (Рабочий стол, Документы — не важно).
   Права администратора не нужны.
2. Дважды кликни "Forge.cmd". Откроется окно Forge (без консоли).
3. Если Windows покажет синее окно "Windows защитил ваш компьютер" — нажми
   "Подробнее", затем "Выполнить в любом случае". Это нормально: так Windows
   реагирует на программы без цифровой подписи.
4. Брандмауэр может спросить про python/pythonw — разреши: это локальный
   сервер отчётов, он слушает только 127.0.0.1, наружу не торчит.

Первый запуск
-------------
На вкладке "Обзор":
  1. "Скачать SDE" — один раз. Статические данные игры большие (~0,5 ГБ на
     диске), первая закачка займёт несколько минут.
  2. "Добавить персонажа (EVE SSO)" — откроется официальная страница входа
     EVE; войди и разреши доступ. Повтори для каждого персонажа.
  3. "Персонажи + рынки структур" и "Рынок Jita и индексы" — синхронизация.
Дальше — "Калькулятор" для любого чертежа и "Что строить" для идей.
Язык: переключатель RUS / ENG в шапке окна.

Свои структуры (необязательно)
------------------------------
"Настройки": свои места (хаб закупки, рынок сбыта, система стройки), станции
с ригами и налогами, фрахт, роли персонажей. Без этого Forge тоже работает —
просто без бонусов твоих структур и без фрахта.

Где твои данные
---------------
Всё в этой папке: forge.db (база), forge.toml (настройки), reports\ (отчёты по
стройкам), .forge\ (состояние окна, кэш иконок). Токены доступа персонажей —
в Диспетчере учётных данных Windows, не в этих файлах. Перенести Forge на
другой компьютер — скопировать папку и заново добавить персонажей.

Если что-то не работает
-----------------------
- Ошибки пишутся в forge_desktop.log рядом с forge.toml.
- Порты сервера отчётов 8000–8010: если все заняты, отчёты не откроются,
  остальная программа работает.

Исходники, обновления, вопросы — на странице проекта на GitHub.
