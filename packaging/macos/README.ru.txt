FORGE {version} для macOS — помощник по индустрии EVE Online
============================================================

Что это
-------
Локальная программа: точное количество материалов и реальная себестоимость
постройки по чертежу, что выгодно строить, расписание джобов по всем
персонажам, отчёты по стройкам. Работает только на этом компьютере и общается
только с официальными серверами EVE (ESI, вход EVE, сервер картинок) и
Fuzzwork (статические данные игры, агрегаты рынка).

Нужен Мак на Apple Silicon (M1 и новее) и macOS {macos} или новее.

Как запустить
-------------
1. Перетащи Forge.app в «Программы» (или куда удобно).
2. Дважды кликни Forge.app. В первый раз macOS скажет, что не может
   проверить «Forge» на вредоносное ПО, — нажми «Готово». Это нормально:
   у программы нет платной подписи Apple Developer ID, только и всего.
3. Открой «Системные настройки → Конфиденциальность и безопасность»,
   прокрути вниз до сообщения про «Forge» и нажми «Всё равно открыть»,
   подтверди паролем или Touch ID. Дальше Forge открывается обычным
   двойным кликом.
   (macOS 14 и старше: правый клик по Forge.app → «Открыть» → «Открыть».)
4. Когда Forge впервые сохраняет токен персонажа, macOS может спросить
   доступ к связке ключей — нажми «Всегда разрешать». После обновления
   программы может спросить ещё раз.

Первый запуск
-------------
На вкладке «Обзор»:
  1. «Скачать SDE» — один раз. Статические данные игры большие (~0,5 ГБ на
     диске), первая закачка займёт несколько минут.
  2. «Добавить персонажа (EVE SSO)» — откроется официальная страница входа
     EVE; войди и разреши доступ. Повтори для каждого персонажа.
  3. «Персонажи + рынки структур» и «Рынок Jita и индексы» — синхронизация.
Дальше — «Калькулятор» для любого чертежа и «Что строить» для идей.
Язык: переключатель RUS / ENG в шапке окна.

Свои структуры (необязательно)
------------------------------
«Настройки»: свои места (хаб закупки, рынок сбыта, система стройки), станции
с ригами и налогами, фрахт, роли персонажей. Без этого Forge тоже работает —
просто без бонусов твоих структур и без фрахта.

Где твои данные
---------------
~/Library/Application Support/Forge: forge.db (база), forge.toml (настройки),
reports/ (отчёты по стройкам), .forge/ (состояние окна), forge_desktop.log.
Кэш иконок — ~/Library/Caches/Forge. Токены доступа персонажей — в связке
ключей macOS, не в этих файлах.
Открыть папку: «Настройки → Система → Данные → Показать» или в Finder
«Переход → Переход к папке…» и вставить ~/Library/Application Support/Forge
Обновление: заменить Forge.app новой — настройки и данные останутся.
Удаление: удалить Forge.app и папку выше.

Если что-то не работает
-----------------------
- Ошибки пишутся в forge_desktop.log в папке данных.
- Порты сервера отчётов 8000–8010: если все заняты, отчёты не откроются,
  остальная программа работает.

Исходники, обновления, вопросы — на странице проекта на GitHub.
